# 笔记与条目格式

## 新建笔记模板

基本信息仅保留已从论文确认的字段，无法确认的字段省略；用户要求完整元数据时可保留并标“未在论文中确认”。占位说明不能作为已填写内容原样留在笔记中。

“空白笔记”也应填写挑战、方法和实验；其他一级标题留空，辅助理解下保留四个二级分类。

```md
# 基本信息

论文名称：[完整标题]

论文作者：[按论文署名顺序列出]

作者机构：[主要作者机构，保留英文名称，可附中文名]

发表时间：[YYYY/MM；仅知年份时标明月份未确认]

发表 Venue：[会议、期刊或预印本平台，注明对应版本]

领域面临的挑战：[本文要解决的领域挑战；概述引言至方法前关键图片表达的内容]

方法概述：[方法、关键技术及模型简称；概述关键方法图，不抄写公式]

实验：[数据集、比较模型或方法、设置与关键结果；概述重要图表的对象、指标或维度、主要观察及其对论文主张的支持]

# 生词

# 写作词汇

# 术语汇总

# 个人理解与问题

# 辅助理解的信息

## 机构/Venue信息

## 相关论文

## 领域术语

## 其他

# 我的想法
```

## 生词

每词一行，采用 `[原词] [词性] [本文语境中的中文含义]`。不能可靠确认词性时省略。

```md
orthogonal adj. 正交的；彼此独立的
```

## 写作词汇

用于积累未来学术写作可复用的表达，与阅读理解用的“生词”分开。每项使用三级标题与七项两列表格。

```md
### [英文词或短语]

| 项目 | 内容 |
| --- | --- |
| 词汇/短语 | [英文表达] |
| 词性/功能 | [动词短语 / 连接词 / 学术名词等] |
| 中文意图 | [写作时想表达的意思] |
| 论文原句 | [必要的原文短引，附页码或章节] |
| 可复用句式 | [以方括号标出可替换部分的句式] |
| 常见搭配 | [2–4 个搭配] |
| 使用提示 | [适用位置、语气强弱、易混表达或限制] |
```

论文原句必须真实；找不到时写“未在本文找到可直接复用的原句”。可复用句式、搭配与提示属于学习性整理，不是论文原话。

## 术语

每项使用二级标题与三项两列表格（加表头共四行内容）。`原文定义` 可以保留英文，`个人理解/说明` 使用中文。

```md
## [术语原文；可附中文名称]

| 性质 | 内容 |
| --- | --- |
| 术语名称 | [术语原文] |
| 原文定义 | [定义性短引，附章节或页码；无定义时说明情况] |
| 个人理解/说明 | [中文译名与白话解释；按需说明它在本文中的作用] |
```

## 个人理解与问题

每项使用三级标题。求证状态四选一，证据应说明论文在哪里回答了问题、回答了哪些部分。未找到依据时如实记录；没有外部补充时省略该行。

```md
### [问题或思考标题]

- 我的理解：[用户提出的理解，或明确标为助手解释的内容]
- 求证状态：[论文内已回答 / 论文内部分回答 / 论文未回答 / 需外部求证]
- 论文依据：[章节、页码或原文要点；没有则写“未找到”]
- 外部补充：[来源链接或完整书目信息；没有则省略]
```

## 辅助理解的信息

按机构/Venue、相关论文、领域术语或其他分类，使用三级标题与以下三项。来源写明是论文、外部检索还是模型已有知识。

```md
### [机构、Venue、论文或背景概念名称]

- 含义：[基础说明；相关论文在此写问题、方法、实验、创新点及重要图表]
- 为什么与本文有关：[帮助理解的具体问题、方法、假设、作者归属或相关工作]
- 来源：[论文章节或页码；外部来源链接或书目信息；或“模型已有知识，未额外检索”]
```

## 我的想法

仅在用户要求记录自己的想法时写入，保留原意；不得把助手推断出的研究方向或观点自动归到用户名下。
