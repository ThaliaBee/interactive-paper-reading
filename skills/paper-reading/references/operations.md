# 基础操作与自动收录

使用 [note-format.md](note-format.md) 中的章节与条目格式。所有操作遵循 `SKILL.md` 的证据、范围及增量修改规则。

## 生成空白笔记

1. 阅读论文，提取已确认的标题、署名顺序、机构、发表时间及 Venue；概括领域挑战、方法与实验。
2. 检查引言、方法、实验中的重要图表，概述比较对象、指标或维度、流程、主要观察及其作用。不转录全部数值、图中细节或公式。
3. 按模板建立文件；`生词`、`写作词汇`、`术语汇总`、`个人理解与问题`、`我的想法`仅保留一级标题；`辅助理解的信息`保留一级标题和四个二级分类，不自动填写具体条目。

## 添加指定条目

| 操作 | 追加位置 | 内容要求 |
| --- | --- | --- |
| 添加术语 | `# 术语汇总` | 二级标题保留原文名称；定义取自相关原文并标定位，中文解释先译名后说明；只写指定术语 |
| 添加生词 | `# 生词` | 每词一行；词性与中文释义以本文出现时的用法为准 |
| 添加写作词汇 | `# 写作词汇` | 三级标题及七项表格；原句有真实出处，句式和搭配服务于未来学术写作 |
| 记录问题或个人理解 | `# 个人理解与问题` | 三级标题；保留用户的疑问或理解，核验论文证据并标明求证状态 |
| 记录用户想法 | `# 我的想法` | 只记录用户要求保留的观点，不擅自补充为用户结论 |

添加背景信息时，转到 [background-research.md](background-research.md)，不要将定向追加扩大成自动收录。

## 自动添加术语

这是覆盖式收录，不是精选摘要。

1. 系统通读摘要、引言、定义、形式化部分、算法说明、定理前提与结论、实现映射、讨论及相关附录，检查论文命名并解释的概念。
2. 收录明确命名，且给出定义、数学形式化、性质、操作语义、机制或作用说明的术语。自然语言定义与形式化定义均在范围内。特别检查以下写法及上下文：
   - `[术语] is / means / refers to …`
   - `we call … [术语]`、`[术语], in which …`
   - `[术语] provides / implements …`
   - `Definition`、`we define`、`is defined as` 引出的概念及其直接变体。
3. 同一概念的紧密变体可以合并，但标题应列出变体，并在解释中分别说明。不能因多个概念出现在同一公式中而漏掉任何一个。
4. 排除仅有日常含义、未被论文专门定义或说明的普通词。定理和引理本身不是术语，除非它们引入可独立使用的命名概念。
5. 为每项保存定义或解释性原文及章节/页码；中文解释覆盖原文紧随其后的说明，以及该概念在本文中的作用。原文仅解释作用时注明“解释性原文，非正式定义”。
6. 写入前按论文各节复查覆盖范围，与已有条目去重；发现候选概念无法确认时报告缺口，不以猜测补齐。

默认不限制条目数量。用户只要求“突出 N 个重点”时，完整收录后可给出 N 项阅读顺序；用户明确要求“只添加 N 个”时遵守该限制，并注明这不是全篇完整术语汇总。

## 生成自动笔记

依次执行：

1. 生成空白笔记，填写基本信息。
2. 自动添加术语，完成默认范围内的完整收录。
3. 根据 [background-research.md](background-research.md) 自动添加相关论文。

除上述三步外，不自动增加生词、写作词汇、个人理解与问题、机构/Venue、领域术语、其他辅助条目或用户想法。若目标笔记已有内容，在保留已有记录的基础上增补，不将“生成”理解为清空重建。

若某一步受全文或网络可用性限制，仍可完成其他有证据支持的工作，并在回复中区分已完成部分与待核验部分。
