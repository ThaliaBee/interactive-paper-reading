# Paper Reading · 计算机科学论文阅读笔记 Skill

一个用于阅读计算机科学论文、持续维护中文 Markdown 学习笔记的 Agent Skill。

重点是把**论文原文、白话解释、外部补充和自己的思考分开**：为术语留下出处，为问题记录求证状态，让笔记既能帮助当下理解，也方便以后回看。

Skill 的入口是 [SKILL.md](skills/paper-reading/SKILL.md)，笔记格式和详细操作说明放在同目录的 `references/` 中。下面以 Codex 为例介绍安装和使用。

## 能做什么

| 操作 | 结果 |
| --- | --- |
| 生成空白笔记 | 填写已确认的基本信息、挑战、方法、实验及重要图表说明，其他栏目留空 |
| 添加指定术语 | 原文名称、定义及出处、中文解释 |
| 添加指定生词 | 单词、词性和本文语境中的中文含义 |
| 添加指定写作词汇 | 论文原句、中文意图、可复用句式、搭配与使用提示 |
| 记录理解、问题或想法 | 保留用户观点；问题注明论文证据与求证状态 |
| 自动添加术语 | 覆盖论文明确命名且定义或解释过的概念，不只挑代表项 |
| 添加指定辅助信息 | 机构/Venue、相关论文、领域术语或其他背景，标明来源 |
| 自动添加相关论文 | 核验与本文问题直接相关的工作，记录来源、问题、方法、实验与创新 |
| 生成自动笔记 | 依次完成“空白笔记 → 自动术语 → 自动相关论文” |

“空白笔记”包含填写好的基本信息；“自动笔记”也不会自动填满所有栏目。生词、写作词汇、个人理解、机构/Venue 背景等内容仍按明确要求添加。

## 快速开始

### 安装

下载本项目后，将 **整个** `skills/paper-reading/` 文件夹复制到目标项目的 `.agents/skills/`，保留内部目录结构：

```text
你的论文项目/
├── .agents/
│   └── skills/
│       └── paper-reading/
│           ├── SKILL.md
│           ├── agents/
│           │   └── openai.yaml
│           └── references/
│               ├── note-format.md
│               ├── operations.md
│               └── background-research.md
├── papers/                      # 自行放入论文，目录名可自定
└── notes/                       # 默认笔记输出目录
```

如果希望跨项目使用，也可复制到用户目录下的 `~/.agents/skills/paper-reading/`。这些本地 skill 目录与调用方式见 [OpenAI 官方说明](https://learn.chatgpt.com/docs/build-skills)。如果安装后没有出现，重启 Codex 再试。

只复制 `SKILL.md` 会丢失模板和详细操作说明；项目内的 `skills/` 是发布源目录，使用时需按上述方式安装。

### 调用示例

以下论文路径与名称仅为示例，请换成自己的文件。显式调用时，在请求中写 `$paper-reading`。

创建笔记：

```text
使用 $paper-reading，为 papers/example.pdf 生成空白笔记。
```

定向添加：

```text
使用 $paper-reading，将论文中的 temporal composability 和 spatial composability
添加到 notes/example.md 的术语汇总，只添加这两个术语。
```

积累词汇：

```text
使用 $paper-reading，在 notes/example.md 添加生词 orthogonal；
再将 in contrast to 作为写作词汇记录，附上这篇论文中的原句。
论文文件为 papers/example.pdf。
```

记录问题与背景：

```text
使用 $paper-reading，阅读 papers/example.pdf，将“作者的独立性假设是否有实验支持？”
记录到 notes/example.md 的个人理解与问题中，并核验论文依据。
另外把会议 ICLR 的背景信息添加到辅助理解的信息，注明 CCF 目录版本与查询来源。
```

完整自动整理：

```text
使用 $paper-reading，为 papers/example.pdf 生成自动笔记。
术语完整收录，相关论文逐篇核验；无法获取或确认的部分请说明。
```

未指定模式、只说“做笔记”时，Skill 默认生成空白笔记；默认输出到执行任务的项目 `notes/`，也可以在请求中指定其他目录。

## 笔记结构

```markdown
# 基本信息
# 生词
# 写作词汇
# 术语汇总
# 个人理解与问题
# 辅助理解的信息
## 机构/Venue信息
## 相关论文
## 领域术语
## 其他
# 我的想法
```

基本信息包含已确认的标题、作者、机构、发表时间、Venue，以及挑战、方法与实验概述。发表时间优先精确到月份，不能确认时不补猜。

术语保留定义出处与中文解释；问题使用“论文内已回答 / 论文内部分回答 / 论文未回答 / 需外部求证”四种状态。`我的想法` 留给用户自己的观点。具体表格及条目示例见 [笔记格式](skills/paper-reading/references/note-format.md)。

默认命名为 `模型简称_论文标题.md`，空格、冒号等不适合文件名的字符替换为下划线。没有明确模型简称时仅使用标题；已有同一论文笔记时增量维护，避免覆盖原有记录。

## 环境与可选资料

本项目提供 Skill 指令与笔记模板，不附带模型、PDF 解析器、搜索服务或学术数据库，也没有必须安装的 Python 或 Node.js 依赖。能力由运行它的 AI 工具提供：

- **阅读论文**：需要能读取论文全文；扫描 PDF 需要宿主支持图像识别或 OCR。关键图表需要实际查看，不能只依赖抽取文本。
- **保存笔记**：需要文件写入能力；普通聊天工具可改为输出 Markdown，由用户保存。
- **外部核验**：机构、Venue、相关论文、期刊 IF 等操作需要可访问的外部来源。没有网络或全文时，只整理已确认内容，并说明缺失范围。
- **CCF 目录**：可选。在请求中指定文件或版本；Skill 也支持读取用户项目中的 `ref/第七版中国计算机学会推荐国际学术会议和期刊目录（正式版）.pdf`。缺少目录时可查 CCF 官方来源，仍不可用则标为未核验，不阻塞其他笔记操作。

CCF 等级需注明目录版本；期刊 IF 需注明指标年份与来源。相关论文有已核验的 arXiv 版本时优先使用，否则提供出版方、作者或机构公开页面。

自动整理涉及完整术语与相关工作收录，长论文可能需要多轮处理。输出会受全文可用性、检索能力与上下文容量影响；未完成的范围应如实列出。
